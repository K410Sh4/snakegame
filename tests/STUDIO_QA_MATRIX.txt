SOLO / CLASSIC — PLAY
[ ] Start with one player. Confirm arena and snake visible; controls WASD/arrows.
[ ] Eat food: score increases exactly once, length increases once, food respawns.
[ ] Wall collision: one death, no continued movement/score; restart works.
[ ] Self collision: death exactly once; no phantom food/segment after restart.
[ ] Rapid alternating and reverse input: no illegal 180-degree turn or desync.
[ ] Full board victory: won state displayed; no nil food or endless tick.

CIRCULAR
[ ] Select ModeCircular, verify server mode and circular bounds; ModeClassic switches back.
[ ] Food only spawns inside valid circle; boundary collision kills consistently.
[ ] Win state/score retained when switching modes or restarting.
[ ] Malformed/oversized/unrecognized remote commands have no gameplay effect.
[ ] Repeated mode changes obey server cooldown; separate player sessions unaffected.

SKINS / HUD / INPUT
[ ] Select Classic/Ember/Frost: correct server-authorized skin shown to all clients.
[ ] Invalid skin command ignored; repeated commands rate limited.
[ ] Desktop 16:9 and 4:3: HUD visible, readable, no overlap; Explorer edits respected.
[ ] Mobile portrait and landscape emulator: touch swipe works and UI remains usable.
[ ] While TextBox focused, swipe/keyboard gameplay input suppressed; after focus restored.
[ ] Window focus loss/recovery clears stale swipe state; no stuck direction.

MULTIPLAYER / SECURITY
[ ] Start local server with 2 clients, then 3; each has isolated snake, arena and score.
[ ] One client's death/restart/mode/skin change does not affect other players.
[ ] Disconnect/reconnect: session and visuals cleaned up; no orphan parts or GUI.
[ ] From test client send nil, number, table, long string, unknown command and spam
    through existing remote; server does not error or grant unauthorized state.
[ ] Repeat all critical tests with high simulated network latency; capture Output.
